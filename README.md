# Number Guessing Game

A Flask web application where users can play a number guessing game with different difficulty levels, track game history, view statistics, and manage accounts.

## Features

- User signup and login
- Difficulty selection
- Number guessing gameplay
- Attempts tracking
- Win/loss result screen
- Play again with same difficulty
- SQLite database persistence
- Game history page
- Statistics dashboard
- User-specific history and stats

## Tech Stack

- Python
- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
